    SINKRONISASI DATA

    Pilih versi data

    Data perangkat dan cloud berbeda. Download backup sebelum memilih versi yang dipakai. Pilihan Anda akan mengganti versi lainnya.

    ZONA BERBAHAYA

    Reset Semua Data

    Tindakan ini akan menghapus seluruh data Site, Client, Tenant, Target Pekerjaan, BAST, aktivitas, pin, Note Pad, serta seluruh data dan master PKBON. Akun/login dan tema tampilan tetap dipertahankan.

    Tindakan tidak dapat dibatalkan.Jika terhubung ke Supabase, data cloud akun ini juga akan dikosongkan.

    PROGRESS PEKERJAAN

    Kelola pekerjaan

    Progres dihitung dari jumlah pekerjaan selesai. Status project tetap dapat diatur melalui Edit Site.

    Tanggal pekerjaan adalah jadwal pelaksanaan. Tenggat adalah batas selesai; pengingat muncul mulai H-3.

    DATA WORKSPACE

    Backup & Restore

    Backup memuat seluruh data kerja, pembayaran, master, catatan, dan gambar PKBON. Akun dan password tidak dimasukkan.

    Restore mengganti data kerja di perangkat ini. Simpan backup terbaru sebelum memulihkan.
